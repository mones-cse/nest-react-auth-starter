# Nest React Boilerplate

A simple authentication boilerplate with NestJS backend and React frontend.

## Tech Stack
- **Frontend**: React + Vite + Tailwind CSS
- **Backend**: NestJS + TypeORM
- **Database**: PostgreSQL (Docker)

- .env
- docker-compose.yml
